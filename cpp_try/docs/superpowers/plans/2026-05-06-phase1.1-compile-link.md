# Phase 1.1: 编译与链接 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 理解 C++ 代码从文本到可执行文件的四步骤（预处理→编译→汇编→链接），动手看到每一步的中间产物。

**Architecture:** 先检查编译环境，再通过一个最小示例逐步展开四个步骤，每个步骤产出中间文件并查看内容，最后用 CMake 自动化整个流程。

**Tech Stack:** MSVC 或 MinGW GCC、CMake 3.16+、终端

### Task 1: 检查编译环境

**Files:**
- Create: `phase1_values_memory/01_compile_link/hello.cpp`

- [ ] **Step 1: 检查编译器是否可用**

```bash
g++ --version 2>&1 || gcc --version 2>&1 || clang++ --version 2>&1
```
如果都没有，检查 MSVC：
```bash
where cl.exe 2>&1
```

- [ ] **Step 2: 创建最小 C++ 文件**

`phase1_values_memory/01_compile_link/hello.cpp`:
```cpp
#include <iostream>

int main() {
    std::cout << "Hello from C++" << std::endl;
    return 0;
}
```

- [ ] **Step 3: 直接编译运行验证**

```bash
g++ -std=c++17 phase1_values_memory/01_compile_link/hello.cpp -o phase1_values_memory/01_compile_link/hello.exe && ./phase1_values_memory/01_compile_link/hello.exe
```
预期输出: `Hello from C++`

### Task 2: 预处理 — 看 `#include` 的本质

- [ ] **Step 1: 只预处理不编译**

```bash
g++ -std=c++17 -E phase1_values_memory/01_compile_link/hello.cpp -o phase1_values_memory/01_compile_link/hello.i
```

- [ ] **Step 2: 查看预处理结果**

```bash
wc -l phase1_values_memory/01_compile_link/hello.i
```
观察：一个3行的 `.cpp` 变成了数万行的 `.i` 文件。`#include <iostream>` 就是把整个 iostream 头文件文本复制粘贴进来。

- [ ] **Step 3: 自己做 include guard 实验**

创建 `phase1_values_memory/01_compile_link/mylib.h`:
```cpp
#ifndef MYLIB_H
#define MYLIB_H

int add(int a, int b) { return a + b; }

#endif
```

创建 `phase1_values_memory/01_compile_link/main.cpp`:
```cpp
#include "mylib.h"
#include "mylib.h"  // 故意重复 include

int main() {
    return add(1, 2);
}
```

预处理并验证不会重复定义：
```bash
g++ -std=c++17 -E phase1_values_memory/01_compile_link/main.cpp -o phase1_values_memory/01_compile_link/main.i
g++ -std=c++17 phase1_values_memory/01_compile_link/main.cpp -o phase1_values_memory/01_compile_link/main.exe && echo "OK"
```

### Task 3: 编译与汇编 — 看 C++ 如何变成机器码

- [ ] **Step 1: 生成汇编代码**

```bash
g++ -std=c++17 -S phase1_values_memory/01_compile_link/hello.cpp -o phase1_values_memory/01_compile_link/hello.s
```

- [ ] **Step 2: 查看汇编文件**

```bash
head -30 phase1_values_memory/01_compile_link/hello.s
```
找到 `main` 函数和 `call` 指令，理解 C++ 函数调用在汇编层面就是一个 `call` 加符号名。

- [ ] **Step 3: 汇编 → 目标文件**

```bash
g++ -std=c++17 -c phase1_values_memory/01_compile_link/hello.cpp -o phase1_values_memory/01_compile_link/hello.o
objdump -t phase1_values_memory/01_compile_link/hello.o 2>/dev/null || nm phase1_values_memory/01_compile_link/hello.o
```
看符号表：`main` 在 `.text` 段，`std::cout` 是 `U`（undefined，等待链接）。

---

### Task 4: 链接 — 多文件项目看符号解析

- [ ] **Step 1: 创建多文件项目**

`phase1_values_memory/01_compile_link/math.cpp`:
```cpp
int multiply(int a, int b) {
    return a * b;
}
```

`phase1_values_memory/01_compile_link/math.h`:
```cpp
#ifndef MATH_H
#define MATH_H
int multiply(int a, int b);
#endif
```

`phase1_values_memory/01_compile_link/use_math.cpp`:
```cpp
#include <iostream>
#include "math.h"

int main() {
    std::cout << "3 * 4 = " << multiply(3, 4) << std::endl;
    return 0;
}
```

- [ ] **Step 2: 分别编译为目标文件**

```bash
g++ -std=c++17 -c phase1_values_memory/01_compile_link/math.cpp -o phase1_values_memory/01_compile_link/math.o
g++ -std=c++17 -c phase1_values_memory/01_compile_link/use_math.cpp -o phase1_values_memory/01_compile_link/use_math.o
```

- [ ] **Step 3: 查看各自的符号表**

```bash
nm phase1_values_memory/01_compile_link/math.o
nm phase1_values_memory/01_compile_link/use_math.o
```
观察：`math.o` 中 `multiply` 是 `T`（defined in text），`use_math.o` 中 `multiply` 是 `U`（undefined）。

- [ ] **Step 4: 链接并运行**

```bash
g++ phase1_values_memory/01_compile_link/math.o phase1_values_memory/01_compile_link/use_math.o -o phase1_values_memory/01_compile_link/use_math.exe
./phase1_values_memory/01_compile_link/use_math.exe
```
预期输出: `3 * 4 = 12`

- [ ] **Step 5: 故意制造链接错误**

仅链接 `use_math.o`（缺少 `math.o`）：
```bash
g++ phase1_values_memory/01_compile_link/use_math.o -o phase1_values_memory/01_compile_link/use_math.exe 2>&1
```
观察 `undefined reference to 'multiply'` 错误——这就是典型的链接错误。

### Task 5: CMake 入门 — 自动化构建

- [ ] **Step 1: 创建 CMakeLists.txt**

`phase1_values_memory/01_compile_link/CMakeLists.txt`:
```cmake
cmake_minimum_required(VERSION 3.16)
project(HelloWorld LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

add_executable(hello hello.cpp)
add_executable(use_math use_math.cpp math.cpp)
```

- [ ] **Step 2: 构建**

```bash
mkdir -p phase1_values_memory/01_compile_link/build
cd phase1_values_memory/01_compile_link/build && cmake .. && cmake --build .
```

- [ ] **Step 3: 运行**

```bash
./phase1_values_memory/01_compile_link/build/hello.exe
./phase1_values_memory/01_compile_link/build/use_math.exe
```

- [ ] **Step 4: 体会 CMake 的作用**

手动删除 `.o` 和 `.exe`，再 `cmake --build .` 一次——一键重新编译全部。
```bash
rm -rf phase1_values_memory/01_compile_link/build/*
cd phase1_values_memory/01_compile_link/build && cmake .. && cmake --build .
```
